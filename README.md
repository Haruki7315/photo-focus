# Photo Focus

A focus timer and clock that shows your own photos. Web app (PWA) for iPad, iPhone and Mac.

Live: https://haruki7315.github.io/photo-focus/

## Commands

- `npm run dev` – run locally
- `npm test` – run tests
- `npm run lint` – check code (also checks that `src/core/` stays pure)
- `npm run build` – build for production

Pushing to `main` deploys to GitHub Pages automatically. See `SPEC.md` for the plan.
