# Photo Focus

Version 1 of a photo + focus timer web app (PWA) for iPad, iPhone and Mac.

- The full spec is in `SPEC.md`. Follow it.
- `reference/playground.html` is a working prototype. Port its logic and look into clean modules; don't copy it as one file.
- Keep `src/core/` free of DOM, React and platform code so we can wrap the app with Capacitor later.
- Work one milestone at a time (SPEC.md section 6). After each one: run tests and the build, commit, give me a short list of things to try on my iPad and iPhone, then wait for me.
- Explain things in short, plain English. I'm still learning, so say briefly why when you make a big choice.
- Never bundle third-party music files.
